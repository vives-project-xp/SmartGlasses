# Deployment Services

This directory documents the services used for local development and small-scale deployments. Each file describes the service's purpose, how to run it locally, important configuration points and operational considerations. Services covered here include the documentation server, backend API, client, object storage (MinIO), lakeFS for dataset versioning, PostgreSQL for metadata, a local Docker registry and convenience UIs such as the registry UI, Heimdall dashboard and Uptime Kuma monitoring.

For advanced cluster tutorials see the k3s guide in the `../advanced/index.md` section.
